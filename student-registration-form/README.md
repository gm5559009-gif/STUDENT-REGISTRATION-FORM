# Student Registration Form

A clean and responsive student registration form built using **HTML5** and **CSS3**. This beginner-friendly project demonstrates common form controls and basic responsive styling.

## Features

- Student name, email, password, and mobile number fields
- Date of birth picker
- Gender radio buttons
- Course selection dropdown
- Address text area
- Required-field validation using HTML attributes
- Responsive layout for smaller screens
- Focus and hover styling for form controls

## Project Structure

```text
student-registration-form/
├── index.html
├── style.css
├── README.md
└── .gitignore
```

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or build tools are required.

## Technologies Used

- HTML5
- CSS3

## Note

This is a front-end demonstration. The form does not store or submit student records to a database. A backend or form-handling service is required for real registration. The current form uses the browser's built-in validation only.
